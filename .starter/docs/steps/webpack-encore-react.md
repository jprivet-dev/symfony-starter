# Steps — Webpack Encore & React

[⬅️ Symfony Starter documentation](../README.md)

---

Follow these steps to reproduce the setup from scratch.

> See https://symfony.com/doc/current/frontend/encore/installation.html

## 1. Generate the project

```shell
make minimalist@lts BRANCH=steps/symfony-ux-webpack-react-sf7.4
```

## 2. Install Webpack Encore

```shell
make require_encore
```

## 3. Install Symfony UX React

```shell
make require_ux_react
```

## 4. Create the application files

> [!NOTE]
>
> Run `make permissions` first to make sure you have the right permissions to create files.

`src/Controller/DefaultController.php`:

```php
namespace App\Controller;

use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Attribute\Route;

class DefaultController extends AbstractController
{
    #[Route('/', name: 'app_home')]
    public function index(): Response
    {
        return $this->render('default/index.html.twig');
    }
}
```

`templates/default/index.html.twig`:

```twig
{% extends 'base.html.twig' %}

{% block body %}
    <div {{ react_component('Hello', { fullName: 'World' }) }}>
        Loading...
    </div>
{% endblock %}
```

The `Hello.jsx` component is auto-generated by the Flex recipe in `assets/react/controllers/`.

And save all:

```shell
git add . && git commit -m "Create the application files"
```

## 5. Build and verify

```shell
make npm_dev
```

Go to https://symfony-starter.localhost:8442/ — you should see "Hello World".
