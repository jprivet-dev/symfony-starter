# Starting with Webpack Encore, Tailwind & React (TypeScript)

[⬅️ Symfony Starter documentation](../README.md)

---

Follow these steps to reproduce the setup from scratch.

## 1. Generate the project

```shell
# Generate a minimalist Symfony application with Docker configuration (LTS - long-term support release)
make minimalist@lts BRANCH=starting/frontend-webpack-encore-tailwind-react-tsx-sf7.4
```

## 2. Install Webpack Encore

```shell
# Install Webpack Encore with Twig pack (add Node.js in the Dockerfile)
make frontend_webpack_encore
```

## 3. Install Tailwind CSS

```shell
make require_tailwind
```

## 4. Install Symfony UX React

```shell
make require_ux_react
```

> [!NOTE]
>
> The Flex recipe inserts a new, active `.enableReactPreset()` line right after `.splitEntryChunks()` — it doesn't uncomment the `//.enableReactPreset()` placeholder further down in `webpack.config.js`. React is enabled either way; the leftover commented line is just a harmless residue from the base Encore template.

```shell
# React's own types aren't bundled with the react/react-dom packages
make npm_save_dev_co a="@types/react @types/react-dom"
```

Build and verify:

```shell
# Install and generate all assets
make assets
```

## 5. Enable TypeScript

```shell
# Pinned to ^6: Encore 7.1.0 only supports typescript ^5/^6, not 7.x
make npm_save_dev_co a="typescript@^6 ts-loader"
```

```shell
# Needed for the require.context() call added by ux-react in app.js
make npm_save_dev_co a="@types/node @types/webpack-env"
```

Create `tsconfig.json`:

```shell
# Generate tsconfig.json
make npx a="tsc --init --jsx react-jsx --types node,webpack-env --declaration false --declarationMap false --esModuleInterop true"
git add . && git commit -m "Generate tsconfig.json"
make permissions
```

| Option                            | Purpose                                                                                          |
|------------------------------------|---------------------------------------------------------------------------------------------------|
| `jsx`                              | Enables JSX syntax for React components                                                          |
| `types`                            | Enables `@types/node` and `@types/webpack-env`                                                   |
| `declaration` / `declarationMap`   | Disabled — not needed for a bundled app, and would make `tsc` emit a stray `.d.ts` next to every component |
| `esModuleInterop`                  | Allows default imports from CommonJS modules (e.g. `import React from 'react'`)                  |

Switch to `app.ts`:

```shell
# Rename app.js to app.ts
mv assets/app.js assets/app.ts
```

In `webpack.config.js`, switch the entrypoint to `app.ts` and enable the TypeScript loader:

```js
Encore
  .addEntry('app', './assets/app.ts')
  // ...
  .enableTypeScriptLoader()
// ...
;
```

```shell
# Needed for ECMAScript imports/exports under verbatimModuleSyntax
make npm a="pkg set type=module"
```

```shell
# Declare the *.css module so TypeScript accepts the CSS import already in app.ts
echo "declare module '*.css';" > assets/global.d.ts
```

Save all and verify:

```shell
# Save all
git add . && git commit -m "Enable TypeScript"

# Install and generate all assets
make assets
```

## 6. Create application files

Switch to `Hello.tsx`:

> [!NOTE]
>
> The `Hello.jsx` component is auto-generated by the Flex recipe in `assets/react/controllers/`.

```shell
# Rename Hello.jsx to Hello.tsx
mv assets/react/controllers/Hello.jsx assets/react/controllers/Hello.tsx
```

Update `assets/react/controllers/Hello.tsx`:

```tsx
import React from 'react';

interface HelloProps {
  fullName: string;
}

export default function Hello({ fullName }: HelloProps): React.JSX.Element {
  return <div className="text-3xl font-bold text-blue-600">Hello {fullName}</div>;
}
```

Create `src/Controller/DefaultController.php`:

```php
<?php

namespace App\Controller;

use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Attribute\Route;

class DefaultController extends AbstractController
{
    #[Route('/', name: 'app_home')]
    public function index(): Response
    {
        return $this->render('default/index.html.twig');
    }
}
```

Create `templates/default/index.html.twig`:

```twig
{% extends 'base.html.twig' %}

{% block body %}
    <div {{ react_component('Hello', { fullName: 'World' }) }}>
        Loading...
    </div>
{% endblock %}
```

Save all files:

```shell
git add . && git commit -m "Create the application files"
```

## 7. Build and see it running

```shell
# Install and generate all assets
make assets
```

Go to https://symfony-starter.localhost:8442/ — you should see "Hello World".

## 8. Makefile daily usage

```shell
make npm_watch  # Compile assets and automatically re-compile when files change
make npm_dev    # Compile assets once
make npm_build  # On deploy, create a production build
```

> [!NOTE]
>
> Run `make` to see all available commands ([makefile.md](.starter/docs/makefile.md)).
